# 分类导入与 AI 入库

带分类 JSON 导入需要 API/Web v261017-2 或更新版本。示例题库：[单文件 JSON](../question-bank/2026-10-17/tech-growth-hub-question-bank-20261017.json)。

## 默认与可选行为

| 情况 | 处理方式 |
| --- | --- |
| 系统没有任何分类，文件包含分类名称 | 确认后自动创建缺失分类并导入，无需手工建分类 |
| 文件分类名称与已有顶层分类相同 | 复用已有分类；不会仅因文件内 ID 不同而重复创建 |
| 题目没有分类，分类 ID/名称为 null、空串或空白 | 进入未分类，不猜分类、不自动调用 AI 分类 |
| formatVersion 2 的 categories 缺省、null 或 []，题目也没有分类引用 | 可以按未分类导入 |
| 只有已失效的数据库分类 ID，没有名称 | 明确报错；选择已有分类或“全部导入未分类”后重新解析 |
| 单文件引用了不存在的分类键 | 明确报错；补齐文件分类，或统一指定已有分类/未分类后重新解析 |
| 下拉列表没有文件中的分类 | 保持“按文件分类自动导入”，系统按文件名称创建，不需要下拉列表预先存在该分类 |
| 手工选择已有分类 | 全部题目统一进入该分类，覆盖文件的分类引用 |
| 手工选择“全部导入未分类” | 忽略文件中的分类 ID/名称，全部进入未分类；受限集成账号仍须遵守授权 |
| 分类表中有多个同名顶层分类 | 提示先整理或指定目标分类，避免猜错归属 |
| 文件格式错误、分类定义重复、名称超长 | 拒绝解析并提示，不会以猜测或丢字段的方式入库 |
| 缺少分类管理权限 | 可导入到已有授权分类；创建缺失分类会被拒绝 |
| 受限集成账号 | 只允许已有授权分类；不能通过创建新分类或“未分类”绕过范围 |

自动创建只支持顶层分类，不会推断嵌套层级。分类名称按去除前后空白后的名称匹配；命名应保持一致。

## 上传一个 JSON

题库 → 导入题目 → JSON格式 → 上传完整 JSON → 保持“按文件分类自动导入” → 解析预览 → 确认导入。

预览显示题目分类名称及待创建分类清单，不写入数据库。确认时只为实际成功导入的题目创建分类；排除题目不会留下空分类。新分类与对应题目在同一事务中保存，失败回滚；提交时重新检查授权。

可以分页核对和取消题目。成功提交同一预览后，重试返回原结果，不会重复写入。换文件或重新建立预览属于新的导入任务，不能当作去重操作。

## 导入后手动归类

在题库找到未分类题目，点击“编辑”，在“分类”中选择已有分类并更新即可；选择“未分类”可取消归类。没有目标分类时先在“设置 → 分类管理”创建。修改需要题目元数据编辑权限。只改分类不会重写独立标题、题干、答案或解析，也不会清除收藏、学习记录；分类变更会保留版本历史。

背题/答题页也可通过“编辑当前题目”修改分类。题目移出当前筛选分类后会刷新列表；若该分类已空，显示“暂无题目”。切题、切换分类或模式会关闭未保存编辑，继续修改前请先保存。

## AI 生成是否兼容

- **AI 粘贴导入**：支持旧 JSON 数组、questions 包装对象和新的带分类 JSON。复制提示词默认要求生成完整分类与题目；无法确定分类时使用 null。生成后仍需解析预览和人工确认。
- **系统内 AI 批量生题**：选择已有分类，或在“新分类名称”中填写名称。生成时不创建分类；点击导入才创建和归类。均不填写时进入未分类。新建分类仍要求分类管理权限。
- **AI 生成失败或内容不完整**：显示错误并保留可用草稿，不把缺少答案的 AI 题目默默作为成功入库。批量入库部分失败时保留失败题，成功题从待入库列表移除；单题失败不移除草稿。
- **AI 答案草稿、字段补充、润色**：围绕已有题目工作，不因生成答案而自动重建或猜测分类。
- **记题页草稿**：继续使用选定分类；未选时进入未分类，并遵守账号分类授权。分类生成规则不会改写本机已有草稿内容。

AI 返回格式可能有误，分类名称也需要人工确认。系统不会因为模型输出了一个数据库 UUID 就允许访问其他题库。

## 数据保留

删除分类不等于删除题目，旧题可能留在未分类中。导入会新增题目，不按标题覆盖，也不会自动清理旧题。若要替换原题库，先完整备份并检查原题目数量；不能直接追加后视为已替换。

分类 JSON 只用于题目和分类，不会覆盖用户、密码、AI Key、收藏或学习记录。完整备份恢复是另一项管理员操作。App 在导入完成后手动更新离线题库即可，不需要重装 APK。

网络中断或服务重启后，先检查题目是否已入库；特别是 AI 批量入库使用兼容导入接口，不能把网络失败直接当作完全未写入后反复提交。导入预览的防重试结果保存在进程内、有效期有限，不是永久去重记录。
