## 2. 版本历史与回退

- 入口：题库单题“历史”/手机菜单“版本历史”，或学习页“版本历史”。
- 展示标题、题干、答案、解析、分类、难度和标签的当前/历史差异；每页 20 个版本。
- 内容修改、属性修改、标签治理、AI 保存和经历题修订脚本均记录版本。旧题库首次修改时补存原始快照；不会伪造以前未保存的修改记录。
- 保存或回退时使用 `expectedRevision` 检查并发修改；旧页面覆盖新内容返回 409。
- 回退需要内容和属性编辑权限；当前题目与历史目标分类都受归属/分类权限约束。受限用户只看到授权分类的历史。
- 回退生成递增的新版本，保留回退前内容。收藏和学习进度不受影响。
- 分类已删除或不属于当前题库时拒绝回退，不会偷偷改成无分类。
- 删除题目会级联删除其版本。合并后可以还原保留题的历史内容；被删除的另一题仍需从完整备份恢复。
- 历史存入 `question_versions`，随完整备份与数据库迁移保存；旧备份缺少版本字段也能恢复。

## 3. 大题库与查重行为

学习只在浏览器保留当前 100 道题，数量和题号采用整个筛选题集。导航接口按 `created_at DESC, id DESC` 寻找相邻题，稳定处理同一创建时间的题目。题号跳转与随机选择覆盖整个筛选题集；定位上次题目会同时检查分类和标签。

查重按权限读取整个题库，使用二元字符集合与全局排序的前缀倒排索引筛选候选，再计算 Dice 分数。标题阈值仍为 0.86、内容阈值仍为 0.72；候选过滤与穷举结果对照通过。相同规范化标题/题干先压缩，避免展开全部相同题的组合。

- 页面展示已扫描/总量、同标题组数、相似题对总数与结果分页。
- 同标题仅表示标题一致，需要核对题干；每组明细每页 20 道，“保留此题，删除本页其余”只处理当前明细页。
- 最多保留相似度最高的 10,000 对，更多匹配仍统计数量，界面明确提示截断；不是只扫描 10,000 道题。
- 任务保存在当前进程内，每个用户最多一个正在执行的任务，全局最多保留 8 个任务，完成任务约 15 分钟后可清理。服务重启或多实例请求落到其他进程时需重新扫描。
- 同标题/相似题比较仍可能产生密集候选，不能保证所有语料线性复杂度。当前实现不提供持久化任务队列或增量索引。

### 万题基准

本机单次合成短文本测试，仅用于确认算法行为与记录数量，不代表生产响应承诺：

| 数据 | 题数 | 耗时 | 实际评分比较 | 匹配对数 | 保留结果 |

## 4. 其他修复

- 登录设置支持 1 小时、1/7/30/90/365 天、自定义 1 分钟至 365 天及一直有效。环境 `JWT_EXPIRES_IN` 默认 7 天，站内设置优先。旧登录沿用签发期限；管理员保存时续签当前登录。
- 一直有效的 JWT 没有 `exp`，认证请求续期持久 Cookie；浏览器仍可清理 Cookie。退出当前设备目前只清理 Cookie，改密可撤销旧令牌。
- 完整备份只允许管理员；分类按父子依赖顺序恢复，拒绝重复 ID、跨题库父分类和循环引用；缺少管理员、外键损坏等恢复失败不会留下部分替换。导出使用一致性快照，计数来自实际导出数据。
- MariaDB 实测发现 JSON 自动解析与现有标签/权限字符串格式不一致。驱动统一保留 JSON 字符串，并将日期转成 UTC ISO 字符串，方便内部跨数据库迁移；毫秒不再被参数处理主动截断。
- MySQL 的 `CREATE INDEX IF NOT EXISTS` 改为先检查索引后创建；补齐用户/创建时间/分类组合索引。
- 合并需要查重、删除、内容编辑和属性编辑权限；保留题更新、版本写入和另一题删除在同一事务中完成。
- 分类范围非空的集成用户不能访问或创建无分类题；空分类范围继续代表整个共享题库。
- 读取/浏览学习进度不再取消已有收藏；新建和更新进度返回数据库实际 ID 和查看次数。
- AI 开关数据库持久化并约束内容推理，配置管理与模型诊断保留。配置文件采用权限 0600 的临时文件原子替换，避免写入中断和默认权限暴露。
- 离线草稿写入等待事务提交；在线启动会刷新服务端身份与权限，网络完全不可达时保留离线草稿入口。
- JSON 导出保存答案、解析、标签、分类 ID、难度；跨题库导入仍需选择有效目标分类。

## 8. 阿里云镜像发布复核

随后进行容器级 MariaDB 完整备份往返时发现，旧 `bulkInsert` 仍对所有日期形状的字符串做转换，并主动截断毫秒：日期格式的题干、答案、标题、解析和设置值可能被改写，版本时间也会变化。这次移除该重复转换，统一由已有的按 SQL 日期列转换函数处理日期参数；业务文本保留原值。

39 项 SQLite API 回归与真实 MariaDB 的新增完整内容往返回归通过。新增 `npm run test:mysql` 已纳入 CI，既比较完整数据集，也显式检查日期格式正文、设置值与版本时间。候选 `v261008-2` 因发现此问题没有发布，修正后的发布版本为 `v261008-3`；镜像与目标主机升级步骤见 [阿里云部署说明](deployment-aliyun.md)。之前的数据库验证覆盖有限，不能作为日期形状内容或毫秒精度已穷尽验证的依据。
