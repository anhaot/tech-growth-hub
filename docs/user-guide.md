# 用户手册

## 1. 系统用途

技术成长站用于管理技术题库、治理知识内容、调用 AI 协助完善题目，并通过背题、答题、收藏和学习进度完成持续复习。

主要角色：

- 学习用户：查看授权题库、背题、答题、收藏和使用获准的 AI 功能。
- 题库维护者：新增和编辑题目，维护分类、标签、重复题和导入导出。
- 管理员：管理用户、权限、AI 凭据、模型、备份和数据库。

页面包括：首页、题库、记题、背题、答题、收藏和设置。页面是否显示取决于当前用户权限。

## 2. 登录与账户

登录需要用户名、密码和图形验证码。默认管理员账号和密码均为 `admin`，首次登录后必须设置至少 9 位且同时包含字母和数字的新密码。

右上角个人资料可以修改用户名、邮箱和密码。登录状态使用浏览器 Cookie；如果刷新后退出，请检查 Cookie、HTTPS 和反向代理域名配置。

有系统管理权限的用户可以在 `设置 → 系统管理 → 登录有效期` 选择 1 小时、1 天、7 天、30 天、90 天、365 天、自定义或“一直有效”。自定义范围为 1 分钟至 365 天。保存后更新当前登录，其他已登录设备在下次登录时使用新设置。

“一直有效”没有应用层的固定过期时间，关闭并重新打开浏览器后可恢复登录。主动退出会清除当前浏览器的登录 Cookie；修改密码会撤销旧登录，并保留改密设备的新登录。清除站点数据、更换域名、服务端更换 JWT 密钥，或浏览器清理长期未使用的 Cookie 后，需要重新登录。

## 3. 首页

首页展示当前题库和学习概况，并提供主要模块入口。数据范围会遵循用户类型和分类授权：独立题库用户查看自己的数据，集成题库用户查看被授权的共享题库。

## 4. 题库管理

题库页是内容维护中心，支持：

- 新增、编辑、查看和删除题目
- 按关键词、分类、标签和难度筛选
- Markdown 答案与解析
- 批量删除、批量标签和 AI 批量标签
- CSV、JSON、Markdown 和文本导入
- 题库导出
- 相似题检查与重复题合并

### 新增和编辑

题干为必填项；标题、答案、解析、分类、标签和难度可以按需填写。答案为空时可以先调用 AI 生成草稿，但保存前应人工确认。

编辑权限分为内容和元信息两类：

- 内容：题干、答案、解析。
- 元信息：分类、标签、难度等。

如果按钮不可见或保存返回无权限，请联系管理员检查对应权限和分类范围。

### 标签与重复题治理

设置中的分类与标签页支持查看标签健康状况、重命名、删除和规范化。重复题功能可以列出相似题并选择保留内容，合并前建议先导出备份。

### 导入与导出

导入前先确认文件格式和字段映射。大量导入完成后建议检查：

1. 题目总数。
2. 分类和标签。
3. 空答案或格式异常题目。
4. 重复题结果。

JSON 导入接受单题对象、题目数组和包含 `questions` 数组的对象，兼容空答案、空解析和旧版 JSON 字符串标签。分类 ID 需要存在于目标题库，也可以在导入时指定目标分类。页面“导出”目前生成便于阅读的 Markdown，分类、标签、难度不会随该文件保存；需要完整恢复系统数据时使用管理员备份功能。

## 5. AI 内容协作

### 批量生题

进入 `题库 → AI批量生题`，填写主题和数量，选择内容深度与模型。生成结果会先展示预览，确认后再导入题库。

### 答案草稿

单题的 `AI答案` 只生成答案、解析和标签建议，不修改题干。可以编辑草稿后保存。

### 题目润色

单题的 `AI润色` 可以优化整道题。轻润色偏表达修正，深润色允许更完整的内容重组。保存前会显示草稿。

### AI 助手

学习页面中的助手能够结合当前题目进行分析、扩展、知识推荐、相似题生成和继续对话。模型选择器会列出设置中的全部已配置模型。

AI 输出不是自动认可的标准答案。用于正式题库或培训内容前应人工复核。

### 版本历史与回退

题库单题“历史”（手机菜单“版本历史”）或学习页“版本历史”可以查看版本差异，选择旧版本并确认回退。回退会生成新版本，保留回退前内容，收藏与学习进度不变。需要同时具备内容和属性编辑权限。

保存或回退时若提示题目已修改，请刷新并核对最新内容。已删除分类的历史版本不能直接回退。旧题目从首次修改开始记录版本，无法恢复此前没有保存的历史。删除题目会删除其历史；合并删除的另一题须通过完整备份恢复。

### 查重与大题库

“检查重复”扫描整个授权题库，显示进度与分页结果。同标题不一定内容相同，应核对题干后处理。每组明细每页 20 道，“保留此题，删除本页其余”只处理当前明细页。合并需要查重、删除和两项编辑权限。

相似结果超过 10,000 对时保留相似度最高的 10,000 对，界面仍显示全部匹配数量和截断提示。任务约 15 分钟后失效，服务重启后重新检查。

### 导出格式

导出按钮旁可选择 JSON 完整字段或 Markdown 阅读版。JSON 保存标签、分类 ID、难度、答案和解析，可以重新导入；跨题库导入请选择有效的目标分类。Markdown 适合阅读，复杂加粗小标题和题目边界可能冲突。

## 6. 背题和答题

### 背题

背题模式适合逐题阅读、回忆和查看答案。可以：

- 上一题、下一题或随机切题
- 显示或隐藏答案
- 记录查看次数和最近浏览位置
- 收藏重点题
- 调用 AI 助手补充解释

### 答题

答题模式适合先组织答案，再与标准答案和解析对照。系统会保存浏览和学习进度，便于下次继续。

筛选条件会影响学习题集；发现题目数量不符合预期时，先检查分类、标签和难度筛选。

学习页面按需加载每页 100 道，上一题、下一题、随机和题号跳转覆盖整个筛选题集；重载时恢复同一题目的位置。掌握程度评分、到期复习队列、作答评分和错题本尚未接入页面。首页“累计查看”是浏览次数，不代表实际学习时长。

## 7. 收藏

收藏页集中显示重点题。可以从题库、背题或答题页面切换收藏状态。收藏不会复制题目，只记录当前用户与原题目的关联。

## 8. 批量内容草稿

`记题` 页面是一个辅助录入入口，适合一次记录多道尚未整理的题目：

1. 一行一道题；较长内容可用空行分隔。
2. 保存到当前浏览器草稿箱。
3. 选择草稿调用 AI 补充答案、解析和标签。
4. 人工检查并编辑。
5. 选择确认无误的内容导入正式题库。

草稿与正式题库隔离。浏览器本地草稿不会自动上传；共享设备使用后应清理草稿和站点数据。

## 9. 分类、标签和权限

设置页根据权限显示以下标签：

- 系统：账户、用户、权限、备份等。
- 分类与标签：分类结构和标签治理。
- AI：API 凭据、模型配置和默认模型。
- 数据库：数据库连接、迁移和校验。

管理员可以为用户设置独立题库或集成题库，并分别授予查看、新增、编辑、删除、导入、AI、标签、备份和系统管理权限。详细规则见 [permissions.md](permissions.md)。

## 10. AI 凭据和模型

### 添加凭据

进入 `设置 → AI设置 → API 凭据`：

1. 填写凭据名称。
2. 填写 OpenAI 兼容 Base URL。
3. 填写 API Key。
4. 保存。

Key 不会显示在模型配置中。一个凭据可以供多个模型使用，编辑凭据后关联模型会一起更新。

### 添加模型

在 `API 配置` 点击“添加配置”，选择凭据、读取模型列表并选择模型。保存后可以设置为默认模型。

### 检查模型

点击“检查模型可用性”后，系统最多同时检查 4 个模型。哪个模型先返回，哪个先显示结果；其他模型继续等待。全部完成后弹窗汇总：

- 可用
- 不可用
- 无法确认
- 其中超时数量

“能读取模型列表”不等于“有权调用模型”。系统会额外执行一次最小推理请求。

## 11. 备份、恢复和数据库

管理员可以导出完整备份。备份包含用户、分类、题目及版本历史、学习数据、AI 配置、API 凭据和系统设置；AI Key 保持加密状态。

恢复文件必须包含至少一个管理员账户。恢复过程中发生数据库写入错误会回滚全部改动，保留恢复前的数据。

恢复或切换数据库前：

1. 导出当前备份。
2. 确认 `AI_CONFIG_ENCRYPTION_KEY` 未改变。
3. 在低峰期执行。
4. 完成后检查登录、题目数量、分类、权限和 AI 配置。

数据库页支持 SQLite 与 MariaDB / MySQL 配置的连接测试、初始化、迁移、校验和重启后切换。

## 12. 常见问题

### 页面更新后仍是旧界面

Windows/Linux 使用 `Ctrl + F5`，macOS 使用 `Cmd + Shift + R`。PWA 环境还可以关闭所有页面后重新打开。

### AI 返回 401

Key 无效、类型不正确或不适用于当前 Base URL。到 API 凭据中更新 Key。

### 模型列表存在但检查失败

提供商可能允许查看目录但未授予推理权限。查看模型行下方的错误详情，尝试其他模型、网络出口或账号。

### 模型检查等待较久

较快模型会先显示结果。慢模型最长等待当前服务设置的超时时间，最终汇总弹窗会单独统计超时或无法确认项。

### 无法删除 API 凭据

仍有模型引用该凭据。先删除关联模型，或把模型切换到其他凭据。

### 题目或按钮看不到

检查当前用户的题库类型、分类授权和功能权限。管理员权限不应通过前端显示判断，最终以后端权限校验为准。

## 导入预览

题库页点击“导入”，选择 CSV、JSON、Markdown 文件或粘贴 AI 返回的 JSON，选好目标分类后点击“解析预览”。此步骤只解析和校验，不写入题库。

- 每页预览 20 道题，展开可查看完整题干、答案与解析；同时显示分类、难度、标签、错误和警告。
- 可取消勾选不需要的题目，跨页选择会保留。错误题目自动排除，空答案等警告允许确认后导入。
- 点击“确认导入 N 道题目”才写入题库；结果展示成功、未导入和主动排除数量，可下载错误明细。相同内容不会自动去重，可在导入后使用题库查重。
- 未指定目标分类时保留 JSON/CSV 中的分类 ID；跨题库导入建议明确选择目标分类。Markdown 可使用“标签：”“难度：”指定属性。
- 更换文件、格式、粘贴内容或分类需要重新解析。单文件最大 10 MB，一次最多 10,000 道；预览保存 15 分钟，服务重启或授权变化后需要重新预览。
- 导入前重新检查分类；若分类已删除，对应题目导入失败。批次按题目返回结果，合法题目仍可成功导入。网络错误时可以再次确认同一预览，服务会返回原处理结果，避免重复写入。

已有 `/api/import/csv|json|markdown|text` 直接导入接口保留兼容；页面使用预览与确认接口。
