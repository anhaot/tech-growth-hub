# AI 功能与模型管理

## 1. 功能边界

AI 是题库建设和学习过程中的辅助能力，主要用于：

- 按主题生成题目草稿
- 为现有题目生成答案、解析和标签建议
- 润色题干、答案和解析
- 分析知识点、扩展答案、推荐关联内容和生成相似题
- 在背题或答题时围绕当前题目继续对话

AI 输出可能不准确。正式入库、覆盖原题或用于学习前，应由使用者检查。

## 2. API 凭据与模型配置

入口：`设置 → AI设置`。

系统把“连接凭据”和“模型配置”分开管理：

- `API 凭据`：保存凭据名称、OpenAI 兼容 Base URL 和 API Key。
- `API 配置`：选择一个凭据，再选择该地址返回的具体模型。

一个凭据可以关联多个模型。更换 Key 或接口地址时，只需编辑凭据，所有关联模型会同步更新。

### 新增自定义模型

1. 点击“添加凭据”。
2. 填写便于识别的名称、Base URL 和 API Key。
3. 保存后点击“添加配置”。
4. 选择“自定义提供商”和刚保存的凭据。
5. 获取模型列表并选择模型。
6. 填写显示名称并保存。

自定义模型表单不会展示 API Key。Key 仅在独立凭据窗口中维护，并使用浏览器自动填充抑制属性，降低密码管理器误填账号密码的概率。

### 默认模型和临时选择

- `默认模型` 是 AI 功能首次打开时的默认选择。
- AI 批量生题、答案草稿、题目润色和学习页 AI 助手会列出当前用户全部可用配置。
- 使用者可以在具体功能中临时选择其他模型，不会因此修改全局默认模型。

## 3. 模型可用性检查

系统不会只依赖 `/models` 列表判断模型是否可用，因为部分提供商会返回账户可见但无权推理的模型。

每个检查包含两步：

1. 从 Base URL 的 `/models` 获取模型目录并确认模型 ID 存在。
2. 发起一次最小对话请求，确认当前凭据确实可以调用该模型。

批量检查最多同时处理 4 个模型：

- 已收到结果的模型立即显示“可用”“已失效”或“无法确认”。
- 较慢的模型继续在后台等待，不阻塞其他模型的界面反馈。
- 全部完成后弹窗汇总可用、不可用、无法确认和超时数量。

状态含义：

| 状态 | 含义 |
| --- | --- |
| 可用 | 模型存在且最小推理请求成功 |
| 已失效 | 模型不存在，或上游明确拒绝当前账户调用 |
| 无法确认 | 网络错误、限流、上游异常或等待超时；系统不会自动删除 |

模型列表可读取但推理失败时，优先检查账户权限、Key 类型、地区访问限制和托管推理服务状态。

## 4. AI 批量生题

入口：`题库 → AI批量生题`。

输入主题、数量和生成要求后，可以选择任一已配置模型。当前提供三种内容深度：

- `速记版`：结构紧凑，适合生成基础题目草稿。
- `练习版`：答案和解析适中，适合作为自测题集。
- `教学版`：解释更充分，适合知识讲解和培训材料。

生成结果先进入预览，确认后再导入正式题库。

## 5. AI 答案草稿

入口：题库中单题的 `AI答案`。

该功能只生成：

- 答案
- 解析
- 标签建议

它不会修改题干、标题或难度。生成后可以编辑文字、选择标签，再保存回题目。

## 6. AI 题目润色

入口：题库中单题的 `AI润色`。

- `轻润色`：侧重表达、错别字和结构调整，尽量保留原意。
- `深润色`：允许重组题干、答案和解析，适合质量较弱的原题。

系统会先显示草稿，只有点击保存才会覆盖题目。

## 7. AI 助手

背题、答题或题目详情中的 AI 助手支持：

- 分析题目
- 扩展答案
- 推荐关联知识
- 生成相似题
- 围绕当前题目继续对话

助手模型选择器会显示设置中的全部模型配置，默认选中系统默认模型。

## 8. 标签协作

AI 可以在答案草稿、题目润色和批量标签中给出标签建议。标签写入前仍由用户确认；对于历史题库，可配合标签健康检查、重命名和规范化功能统一标签体系。

## 9. 安全与数据处理

- API Key 通过 AES-256-GCM 加密存入数据库和备份。
- 配置、凭据和题目接口均校验用户归属与权限。
- 自定义 Base URL 执行协议、主机和 DNS 解析安全检查。
- Key 不通过配置查询接口返回给前端。
- 删除仍被模型使用的凭据会被拒绝，避免生成无效配置。

不要把不受信任的代理地址、共享 Key 或来源不明的兼容接口加入生产系统。

## 10. 常见问题

### 返回 401

通常表示 Key 无效、Key 类型不适用于当前接口，或认证头不被上游接受。更新凭据后，关联模型会自动使用新 Key。

### 能获取模型但调用返回 404 或无权限

`/models` 可能是提供商级目录，不代表账户拥有每个模型的推理权限。换一个已授权模型，或向提供商开通对应托管端点。

### 检查超时

系统正常访问模型目录但对话接口长时间不返回时，通常与出口网络、地区限制、账户权限或上游托管服务有关。可以更换网络出口、凭据或提供商交叉验证。

### 浏览器把账号密码填到 Key 输入框

系统已把 Key 独立到 API 凭据窗口，并加入自动填充抑制。若浏览器扩展仍强制填充，可在密码管理器中删除该站点的错误匹配记录。

## 全局开关与历史

AI 开关保存在 `system_settings.ai_enabled`，重启后保持；关闭时服务端拒绝内容生成、答案草稿、润色、对话与批量标签请求。模型配置与诊断仍可使用，诊断会发起最小推理请求。

保存 AI 答案、润色或标签会记录题目版本；误覆盖时可在单题版本历史中比较并回退，保存还会检查并发修改。
